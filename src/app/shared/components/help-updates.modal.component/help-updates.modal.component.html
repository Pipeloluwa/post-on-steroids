folder_special Capsules & Request Organization

Capsules let you group related API requests together into isolated workspaces. You can create multiple capsules from the Capsules submenu or dropdown. Tabs remain open per capsule and are persisted even across application sessions.

data_object Dynamic Variables ({{ '{{var}}' }}) & +Var

Reference variables anywhere in URLs, headers, params, or request bodies with {{ '{{variableName}}' }} syntax. Use the +Var button or highlight text in Monaco Editor to bind a variable directly to a response property, header, or param. When the source request executes, bound variables automatically sync with the latest values, preventing stale data or duplicate entries.

alt_route Chained Request Triggers

Chain multi-step API sequences with the Trigger dropdown located right next to Auto-Auth. Select any request in your capsule to be automatically fired once the current request returns a successful response.

fact_check Test Scripts & Standard Assertions

Verify API behavior with the built-in Sandbox. Choose from 19 standard assertions via the Add Snippet... dropdown covering status codes (200, 201, 204, 2xx, 4xx, 5xx), performance thresholds (<200ms, <500ms, <1000ms), JSON body properties, nested token existence, array checks, and headers.

bookmarks Saved Examples & Background Pre-loading

Save successful request/response snapshots as examples for quick reference. Examples are pre-fetched asynchronously in the background so they are instantly ready when expanding any request's chevron.

sync_saved_locally Full Session & Response Persistence

Your workspace state—including active capsules, open tabs, active tab focus, variables, and complete response viewer results (status, body, headers, timing, and test reports)—is automatically preserved across logout and restored upon sign-in.
