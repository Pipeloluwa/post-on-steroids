folder_special Capsules & Request Organization

Capsules let you group related API requests together into isolated workspaces. You can create multiple capsules from the Capsules submenu or dropdown. Tabs remain open per capsule and are persisted even across application sessions.

send Sending Requests & Payloads

Support for all standard HTTP verbs (GET, POST, PUT, DELETE, PATCH, etc.). Configure query parameters, headers, or body (JSON, XML, Form-Data, or raw text). When unwrapped, payload text collapses to a single minified line for quick inspection.

data_object Global Variables ({{ '{{var}}' }})

Reference global variables anywhere in your URL, headers, query parameters, or request body using double braces syntax: {{ '{{baseUrl}}' }}. Use the + Var buttons in request rows or response viewer to instantly save any value into Global Variables.

javascript Pre-Request & Post-Response Scripts

Write scripts to compute authentication tokens, inject dynamic timestamps into headers, or evaluate automated assertions on status codes and response bodies.

share Sharing & Importing Capsules

Share any capsule with teammates via one-click generated links. Recipients can import the entire collection using the Import Shared Capsule card or by pasting the share token.

mouse Right-Click Tab Actions

Right-click any horizontal tab to reveal context actions: Close Tab, Close Other Tabs, Close All Tabs, or Duplicate Tab.
