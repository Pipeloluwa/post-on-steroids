folder_special Capsules, Multi-Select Request Folders, Auto-Save Order & Tab Navigation

Capsules let you isolate API workspaces while Postman-style Request Folders keep endpoints organized inside each capsule. Multi-select requests using Shift+Click, Ctrl+Click, or checkboxes and drag all selected requests directly into any folder. Folders themselves can be dragged and repositioned in any order alongside individual requests—every folder or request rearrangement and folder assignment auto-saves automatically. You can also navigate across your tab visit history using the Back / Forward buttons.

data_object Dynamic Variables ({{ '{{var}}' }}), +Var & $ Utilities

Reference variables anywhere with {{ '{{variableName}}' }} or bind live response fields using +Var. Type $ in the URL bar, Headers, Form-Data, or Request Body editor to open built-in utility generators ($guid, $timestamp, $randomEmail, etc.)—choose between Dynamic tokens ({{ '{{$guid}}' }}) that regenerate automatically before every request execution or One-Time static values.

alt_route Auto-Auth, Chained Triggers & Full Portability

Chain multi-step API sequences with Auto-Auth and the Trigger selector so dependent requests fire automatically. When you Export, Share via Link, Import, or Duplicate a capsule, all request folders, custom ordering, Auto-Auth endpoints, Post-Response Triggers, request settings, encryption configs, and dynamic +Var bindings are preserved and remapped automatically.

fact_check Isolated Script Consoles & Cloud Default Scripts

Verify API behavior with 19 standard test assertions and custom Pre-Request, Post-Response, and Encryption/Decryption scripts. Each script stage logs exclusively to its own isolated Script Console view, and edited default script templates sync to the cloud for authenticated users.

bookmarks Saved Examples & Background Pre-loading

Save successful request/response snapshots as examples for quick reference. Examples are pre-fetched asynchronously in the background so they are instantly ready when expanding any request's chevron.

sync_saved_locally Full Session & Response Persistence

Your workspace state—including active capsules, request folders, open tabs, active tab focus, variables, and complete response viewer results (status, body, headers, timing, and test reports)—is automatically preserved across logout and restored upon sign-in across devices.

lock URL-Encoded, GraphQL & Raw Text with Field-Level Encryption Locks

Build and test x-www-form-urlencoded forms, dual-pane GraphQL queries and JSON variables, and raw plaintext bodies. Click the individual gutter lock icon (🔒) on any Form-Data or URL-Encoded row to encrypt specific sensitive parameters before dispatch, or toggle Auto-encrypt to secure all active fields with 1 click.

code XML & SOAP 1.1 / 1.2 Web Services & Multi-Style Text Wrap

Construct enterprise SOAP web service calls with W3C-compliant Envelope, Header, and Body templates. The app automatically detects SOAPAction headers and negotiates content types. Format payloads with 4 dedicated views—Pretty, Key-Field, Soft Wrap, and Collapsed—with full non-destructive undo/redo history (Ctrl+Z / Ctrl+Y).

drive_file_move Sidebar Inline Renaming, Duplication & Cross-Capsule Folder Transfers

Duplicate or rename requests directly from the left sidebar tree without opening extra modals. Rename capsules right inside the workspace header bar. Transfer entire group folders and all member requests to another capsule in one click via Copy or Move mode with automatic structure mapping.
